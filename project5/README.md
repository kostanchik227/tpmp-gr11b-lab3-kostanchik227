# project5 — Абитуриенты SQLite

## Description
Консольное приложение на языке C для работы с базой данных SQLite.

Вариант: Абитуриенты и ВУЗы.

Функционал:
- SELECT
- INSERT
- DELETE
- parameterized queries
- INNER JOIN
- COUNT / SUM / MAX / MIN
- AUTOCOMMIT
- TRANSACTION
- работа с фото (BLOB)
